4 · Prompts por bloque

Cada bloque contiene un fragmento del documento + instrucciones. El prompt está diseñado para obtener respuestas extensas, concretas y específicas (artículos, plazos, requisitos, definiciones y autores), no generales. El modo predeterminado pide usar toda la capacidad útil de salida mediante artefacto/canvas. Si el fragmento es más grande de lo que admite el chat, use Modo adjunto: descarga el texto como archivo, adjúntelo en Claude/ChatGPT y pegue solo el prompt.

6 · Consolidación

Con las respuestas parciales el sistema arma un prompt de consolidación que pide a Claude/ChatGPT generar todos los productos en un formato estructurado. Copie el prompt, ejecútelo, y pegue la respuesta consolidada. En obras muy extensas la consolidación se divide automáticamente en etapas + un prompt de fusión final.
